# 🟣 NYE Tube - Purple Themed YouTube Clone

A custom, dark purple-themed clone of the YouTube homepage interface built using modern **HTML5** and **CSS3**.

## 💜 About The Project

I created **NYE Tube** because my favorite color is purple, and I wanted to transform YouTube's traditional interface into a custom dark aesthetic. 

This project was built while following along with [SuperSimpleDev's HTML & CSS Full Course on YouTube](https://www.youtube.com/watch?v=G3e-cpL7ofc).

## ✨ Features

- **Custom Purple Theme:** Designed with a dark neon purple palette, glowing accents, and styled buttons.
- **Header & Search Bar:** Custom top navigation bar with search inputs, action icons, and a branded logo.
- **Sidebar Navigation:** Re-created YouTube navigation bar containing main links (Home, Shorts, Subscriptions, Library, etc.).
- **Responsive Video Grid:** Displays video cards with custom hover animations, glowing borders, and video meta information.
- **Category Filter Pills:** Custom scrollable category filter buttons across the top of the feed.

## 🛠️ Built With

- **HTML5:** Semantic markup structure.
- **CSS3:** Custom CSS variables (`:root`), Flexbox, CSS Grid layouts, and CSS hover transitions.
- **Font Awesome:** Scalable vector icons for interface action buttons.

## 🚀 Getting Started

To view this project locally on your machine:

1. Clone or download this repository.
2. Open `index.html` directly in any modern web browser (like Google Chrome).
